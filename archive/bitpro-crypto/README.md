# Archived BitPro crypto leftovers

These files are **not** on the StockPro A-share product path.

They were moved here so Paper, backtest, and the default tree cannot import
OKX/Binance live exchanges, contract brokers, or funding/arbitrage strategies.

Do not add this directory to `backend/app` or `scripts/` without an explicit
crypto profile and a new contract. Live trading stays off.
