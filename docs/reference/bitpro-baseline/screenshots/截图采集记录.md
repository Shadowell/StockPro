## 重新采集规则

1. 从已部署环境采集，不使用 mocked 静态数据。
2. 使用普通浏览器导航，不拦截网络响应。
3. 只有当空态、部分态或错误态是真实部署状态时才保留，并在本文件记录该状态。
4. 每次替换 README 截图都要更新本文件。
5. 如果 UI 文案变化影响截图，先部署，再从已部署页面重新采集。
