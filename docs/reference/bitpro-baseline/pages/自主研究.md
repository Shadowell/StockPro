# 自主研究页面设计

## 路由

- Route: `/arc`
- Frontend owner: `frontend/src/pages/ArcConsole.tsx`
- Backend owner: `backend/app/api/v2/endpoints/arc.py`
- Upstream owner: HyperTrade `backend/src/hypertrade/arc/`（`router.py`、`pipeline_view.py`、`evidence_view.py`）

## 页面目的

`自主研究` 是 HyperTrade ARC 的操作台。操作者在这里启动研究任务、实时跟踪整条流水线走到哪一步、审阅候选证据，并对模拟盘幸存者做唯一一次实盘审批。BitPro 只做代理和渲染：候选生成、门禁判定、观察窗和审批包都由 HyperTrade 拥有，页面不复制其判定逻辑，也不在前端重算进度。

## 页面结构

页面沿用 BitPro 主力页面（如复盘中心）的视觉语言：`rounded-xl` 卡片、蓝色主强调色、页头卡加元信息 chip、KPI 行、`bg-crypto-bg` 表头的标准表格、虚线空态。不要照搬因子页的直角青色风格，那是全站个例。

- 页头为一张卡：`Bot` 图标、`自主研究` 标题、`HyperTrade ARC` 与 `仅管理员` 标记，下方三枚元信息 chip（任务数、更新时间、`实盘需人工审批` 边界声明），右侧 `刷新`。
- 启动卡为单行栅格：研究目标、标的、周期、候选预算和 `启动研究`；未配置上游时整条禁用。
- KPI 行四张卡：当前阶段、总进度、候选/存活、模拟盘观察。栅格断点为 1 / 2 / 4 列，窄屏单列以免大号数值被截断。
- 主区在 XL 断点为 `300px` 任务列表加自适应详情区，窄屏改为上下堆叠。
- 任务列表每行显示目标、标的/周期/状态、流水线进度条、当前阶段名和 `阶段序号/总数 · 百分比`，待审批任务带 `待审批` 标记。
- 详情区首屏是 `流水线进度`：总进度条加七个等高阶段卡（目标编译、候选探索、红队对抗、BitPro 验证、模拟盘观察、实盘审批、实盘灰度）。每张卡有阶段图标、状态标记、本阶段计数说明和本阶段进度条。
- 阶段状态四色：已完成翠绿带对勾、进行中蓝色带脉冲点、阻塞琥珀色带禁止图标、未开始灰色。任务阻塞时在流水线下方展示中文阻塞原因、上游 message 和缺口标签。
- 详情区下半为 `候选证据` 表加右栏 `活动流` 与 `实盘审批`。点击候选行在表格下方展开策略源码，可收起。
- 活动流按时间倒序显示最近 12 条事件，每条为事件中文名、时间和白名单标量字段。

## 数据来源

- 配置：`GET /api/v2/arc/config`，只回布尔位，不回令牌或签名密钥。
- 任务列表：`GET /api/v2/arc/missions`，每行的 `pipeline` 徽章由 HyperTrade 计算。
- 流水线进度：`GET /api/v2/arc/missions/{id}/progress`，阶段、阻塞原因、活动流全部来自上游投影。
- 候选证据：`GET /api/v2/arc/missions/{id}/evidence`；候选源码：`GET .../candidates/{attemptId}`。
- 审批：`POST /api/v2/arc/missions/{id}/decide`。
- 页面不得伪造阶段、不得在前端估算百分比、不得在证据缺失时显示占位数值。

## 实时刷新

- 存在运行中任务时，任务列表每 5 秒轮询一次。
- 选中任务未完成时，进度每 3 秒轮询一次；证据只在 `eventCount` 变化时重读，避免无谓请求。
- `更新于 N 秒前` 以上游 `secondsSinceUpdate` 为基准叠加本地经过时间，不受浏览器与服务器时钟偏差影响。
- 任务完成或阻塞后停止进度轮询，页头指示灯从 `实时轮询` 变为 `已停止`。

## 交互和安全边界

- 整个 `/api/v2/arc` 前缀仅管理员可访问，Guest 会话在鉴权中间件层被拒绝。
- 浏览器不持有 HyperTrade 服务令牌或审批签名密钥，全部经 BitPro 服务端代理。
- 审批操作人取自已验证会话，请求体携带 `operator_id` 会被拒绝为 422。
- 审批包存在 unknowns 时前端禁用 `批准实盘`，上游同样在服务端拒绝，不依赖前端防守。
- 活动流只渲染上游白名单标量，策略源码仍然只在候选下钻里出现。

## 加载、空态和错误态

- 未配置上游时展示琥珀色提示并列出缺失的环境变量名，页面其余部分保持可见但禁用。
- 进入页面自动选中最新任务，避免详情区首屏是一大片空白；确无任务时才显示引导空态。
- 选中后加载中显示固定高度加载面板，不产生布局跳动。
- KPI 在未选中任务或上游未回该项证据时显示 `--` 与说明文案，不填充猜测值。
- 任务为空、候选为空、活动流为空各有独立空态，不插入假行。
- 接口失败时展示真实错误摘要，保留刷新入口，轮询失败不清空已渲染数据。
