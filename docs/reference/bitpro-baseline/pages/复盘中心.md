# 复盘中心页面设计

## 路由

- 路径： `/review`
- 组件： `frontend/src/pages/ReviewDashboard.tsx`
- 侧边栏标签/图标： `复盘` / `ClipboardList`

## 页面目的

复盘中心是运行中模拟盘策略的小时级研究看板。它从 `status=running` 且 paper/simulation 的策略权益采样和成交记录中聚合表现，用于识别哪些策略画像值得继续观察，哪些策略需要复查、降仓、暂停或等待更多样本。

该页面不承担策略启停、实盘订阅、真实账户监控或外部交易执行职责；这些操作仍分别归属 `/live`、`/live-real` 和 `/monitor`。

## 首屏布局

- 页面使用现有 BitPro 全宽工作台壳：`p-6 h-full`、暗色背景、`bg-crypto-card` 卡片、`border-crypto-border` 边框和蓝色侧栏激活态。
- 顶部使用紧凑工作台状态栏，左侧是小号 `ClipboardList` 图标、`复盘中心` 标题和 `运行中模拟策略` 身份标；标题下方以字段化状态单元展示 `刷新 1H`、`最新 <时间>`、`口径 仅模拟盘`，右侧保留 `24H / 7D / 30D` 分段窗口和蓝色 `刷新` 按钮；窗口选中态使用全站统一黄色底色。
- 第一行六个 KPI 卡片展示：组合权益变化、中位权益变化、最大回撤、可继续观察、需要复查、样本健康度。卡片使用紧凑字体、内阴影和细边框，不显示右上角图标角标，不使用营销式大块 hero 或独立侧栏。
- 第二行左侧是 `策略分层评分矩阵`，按资产、K 线周期、策略类型和资金版本合并；表头采用小字号 uppercase 节奏，表体保留 hover 行反馈。点击任一策略组行可在表格内展开该组的运行中模拟策略列表，列表展示策略名、权益变化、回撤、胜率、盈亏比、交易数、评分、判断和结论标签。右侧是 `策略好坏榜`，拆成 `值得继续观察` 与 `需要复查/等待` 两列，每个策略以小卡片显示评分、权益变化、回撤、交易数和标签。
- 第三行左侧是 `小时权益变化热力图`，每个小时格子使用全站涨跌色变量叠加强度和内阴影；右侧是 `复盘结论标签` 和带编号、图标、箭头的 `下一步建议`。
- 页面底部保留复盘口径说明，明确只读模拟盘事实，不读取真实账户状态。

## 视觉规则

- 分区标题统一使用小号图标胶囊、`text-sm` 标题和右侧轻量 meta 标签，与监控、模拟盘详情页的深色面板节奏一致。
- 页面图标使用 `lucide-react` 现有图标，不引入自绘 SVG、独立品牌标或页面专属侧栏。
- 字体层级保持工作台密度：页面标题使用紧凑 `text-xl`，分区标题使用 `text-sm`，榜单、表格和标签使用 `text-xs` / `text-[10px]`；卡片和展开列表内长策略名使用截断或两行截断，避免撑破布局。
- 卡片、榜单、表格和建议行统一使用 `rounded-xl` / `rounded-lg`、`border-crypto-border`、`bg-crypto-card` 或 `bg-crypto-bg`，不使用浅色表格、渐变背景、大圆角装饰块或概念图式容器。
- 权益变化相关文字和热力图格子必须继续读取全站涨跌配置，默认红涨绿跌；风险、告警、评分等级可以使用独立状态色，但不能替代权益变化色语义。

## 数据来源

- `GET /api/v2/review/summary?window=24h|7d|30d&bucket=1h`
- `strategies`：策略名称、运行状态、资产类型、K 线周期、策略类型、资金版本和 paper/live 边界；只有 `status=running` 的模拟策略进入聚合。
- `strategy_equity_samples`：每个策略的权益、权益变化、胜率、盈亏比和时间序列采样。
- `strategy_trades`：窗口内成交数量、平仓胜率、平仓盈亏和盈亏比。

`/review` 只纳入 `status=running` 且 `is_paper_trading=true` 或默认 paper 的策略。暂停、停止、未启动的模拟策略不进入复盘统计；`is_paper_trading=false` 的真实实盘策略、OKX 私有账户权益、余额、持仓、订单和全局真实账户风控状态都不得参与评分。

## 交互规则

- 窗口切换只改变聚合窗口，不修改策略状态、不触发回测、不启动服务。
- 页面每小时自动刷新一次，并允许手动刷新；刷新仅重新请求 `/review/summary`。
- 后端以运行中模拟策略的最新有效权益采样为 `updated_at` 锚点，向前计算所选窗口，避免已停止或暂停策略的旧样本把复盘窗口带偏。
- 综合评分同时考虑权益变化、最大回撤、胜率、盈亏比、成交数和样本数；低样本策略自动降权。
- `策略分层评分矩阵` 的 `判断` 至少覆盖 `继续观察`、`稳健低频`、`样本偏少`、`等待样本`、`复查降仓`、`暂停复查`。
- `复盘结论标签` 至少覆盖 `稳健盈利`、`高收益高回撤`、`持续失血`、`权益回落`、`胜率高但赔率差`、`样本不足`、`马丁回撤风险` 和 `待继续观察`。当策略成交少于 2 笔或权益采样不足时，负向变化标记为 `权益回落`，不直接标记为 `持续失血`。
- 权益变化、榜单和热力图色彩必须跟随全站涨跌配色配置：正向变化使用 `text-up` / `--color-up`，负向变化使用 `text-down` / `--color-down`，默认口径为红涨绿跌；灰色只表示近似持平或无交易。

## 空态和错误态

- 没有运行中模拟盘权益采样时，页面显示真实空态，提示启动策略后自动聚合，不渲染示例行。
- API 错误时，页面顶部显示后端错误信息，并保留当前窗口控件与手动刷新入口。
- 某个区域没有数据时，只显示该区域空态，不影响其他区域展示。
- 样本不足不应伪造成有效结论，而应在评分、标签和下一步建议中显式暴露。
