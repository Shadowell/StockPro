# 行情页面设计

## 路由

- 路径： `/market`
- 组件： `frontend/src/pages/Market.tsx`
- 侧边栏标签/图标： `行情` / `TrendingUp`

## 页面目的

行情 is the focused real-time market inspection workspace. It lets operators switch between contract and spot instruments and inspect K-lines, order-book context, and EMA overlays without rendering the separate full trade-pair universe list.

## 首屏布局

- Header left of the K-line workspace contains the detail-view `合约 / 现货` switch and symbol selector.
- The symbol selector shows the same shared symbol icon as Home rankings: remote logo when available, deterministic local fallback when the asset has no supported logo.
- Timeframe controls sit on the same header row, aligned to the right, and render compact uppercase granularity labels such as `1M`、`15M`、`1H` and `1D` even though API requests keep lowercase values such as `1m` and `1h`.
- Main area prioritizes the K-line chart with EMA legend/value strip; EMA line colors, legend/tooltip markers, and value-strip colors must match, and EMA tooltip/value-strip numbers render with 5 decimal places.
- 当前标的详情头在价格行下方展示本标的 `24h 高 / 低 / 量 / 额`；合约模式额外展示标记价、资金费率和下次结算时间。这些字段来自实时 ticker 与公开资金费率接口，不是已移除的完整市场列表行。
- K 线主图默认叠加 EMA5/10/20/30，下方副图默认展示成交量、RSI(14) 与 MACD；RSI/MACD 序列来自 `/api/v2/market/indicators`，前端不得本地重算。
- 右侧面板上半为订单簿，下半为最近成交列表（公开 `/market/trades`），用于填满详情侧栏空白。
- Toolbar actions stay compact: refresh and connection state.
- The page does not render the full `市场列表` panel, market-list search, favorite stars, 24h range rows, or `合约 / 现货 / 币币 / 自选` universe tabs above the chart.

## 数据来源

- `/api/v2/market/klines` from the file K-line store first, then legacy fallback/fetch behavior.
- `/api/v2/market/indicators` for EMA/RSI/MACD overlays.
- `/api/v2/market/trades` for recent public trades under the order book.
- OKX public ticker/order-book data for live quote context；合约资金费率来自 `/api/v2/funding/rate/{symbol}`。
- Kairos prediction endpoints are not exposed by the market API.

## 交互规则

- Changing market type converts the current base between `BASE/USDT:USDT` and `BASE/USDT` when possible.
- 页面默认市场类型为合约；当全局暂存 symbol 仍是现货格式时，只加载合约 symbol 列表并完成格式归一，不得先请求现货 K 线、指标和订单簿再重复请求合约数据。
- 标的选择器默认只展示主流 Top 50，但输入搜索词后必须检索当前市场类型接口返回的全部交易对；搜索应同时接受 `KAITO`、`KAITO/USDT:USDT`、`KAITO-USDT-SWAP` 和 `KAITOUSDT` 等常见写法，并在匹配时忽略 `/`、`-`、`:` 等分隔符。
- Changing symbol or timeframe must ignore stale in-flight responses.
- Home ranking row clicks may navigate here with the selected symbol already applied.

## 空态和错误态

- Missing real K-lines should surface as a clear chart/data error.
