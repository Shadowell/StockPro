# 策略页面设计

## 路由

- 路径： `/strategy`
- 组件： `frontend/src/pages/Strategy.tsx`
- 侧边栏标签/图标： `策略` / `Code2`

## 页面目的

策略 is the strategy registry and review workspace. It lets operators inspect built-in and generated strategies, understand asset class, symbol scope, strategy logic, and runtime-readiness before launching backtests or simulations.

## 首屏布局

- Header identifies the strategy library.
- Header actions render as framed controls: `AI 写策略` uses a purple-tinted secondary button with visible background fill and `新建策略` remains the blue primary action, so both actions read as clickable buttons rather than plain text.
- The `我的策略 / 策略广场` tab switcher is a compact content-width segmented control, not a full-width framed bar. 页签以及资产、状态、策略类型、周期和资金版本筛选的选中态统一使用全站黄色底色。
- Filters reuse the simulation center's independent segmented-control style rather than a framed filter panel: the second row shows asset class, runtime status, and strategy type (`全部 / CTA / 马丁 / AI / 做市`), while the third row shows K-line timeframe and capital version. Search stays visible beside the filter controls without hiding the strategy list shell.
- Strategy cards show canonical strategy names, asset-class coloring, symbol scope, timeframe, and key metadata. Visible K-line granularity labels on cards, filters, and details use uppercase compact tokens such as `1H` rather than raw lowercase config values such as `1h`. `我的策略` 加载骨架、卡片列表和 `策略广场` 模板在桌面宽屏使用四列网格（`lg:grid-cols-4`），平板两列、手机一列，不再使用三列。
- 策略详情展示 `核心标的` 与 `交易逻辑` 等可解释信息；统一使用“标的”覆盖股票、加密货币、现货、永续合约和商品，不使用仅适用于股票的“选股”。

## 数据来源

- Production/local `strategies` table through strategy APIs. The `/strategy` library list uses paginated `GET /api/v2/strategies?page=...&per_page=...` requests with server-side fuzzy search plus status, asset-class, strategy-type, K-line timeframe, and capital-version filtering in the visible UI. The paginated API supports `strategy_type=all|cta|martingale|ai|market_making`, returns counts with the `cta` and `market_making` keys, and rejects the old `ctr` spelling. Count summaries mirror the simulation center: active filter controls affect peer counts, while search is applied after the controls and only narrows the final card list. Legacy `/api/v2/strategies` calls without `page` still return the full array for existing consumers.
- Seed definitions from `data/seed/strategies.json` for canonical built-in metadata.
- Strategy config JSON for selection logic, trading logic, risk parameters, symbols, and timeframe.

## 交互规则

- Asset-class filtering uses config, canonical name prefixes, and contract symbol shape.
- Strategy-type filtering uses `全部 / CTA / 马丁 / AI / 做市` chips. `做市` maps to `strategy_type=market_making`, canonical `[做市]` names, or market-making strategy keys; `AI` requires explicit `[AI]`/AI autonomous metadata instead of loose substring matches.
- K-line filters use compact `1M / 5M / 15M / 30M / 1H / 4H / 12H / 1D` labels, backed by normalized config or canonical name tokens.
- Capital filters use `全部` / `100U` / `1000U` / `10000U`, preferring config capital fields before falling back to canonical names.
- Search uses the same operator rhythm as the simulation center search shell. It matches strategy name, description, symbol list, asset/status labels, normalized period/type/capital metadata, and config JSON, splitting typed text into tokens so operators can combine symbol, period, and type terms. Matching ignores spaces and common separators such as `/`, `-`, `_`, `:`, `.`, `·`, and Chinese punctuation.
- The `我的策略` tab renders 18 strategy cards per page, keeps filters visible while loading, and exposes compact previous/next pagination controls below the cards.
- Admin strategy actions may open AI generation, create/edit templates, or delete stopped strategies. Guest sessions are read-only in this page: `AI 写策略`, `新建策略`, template creation, edit, save, and delete controls are hidden or blocked, while list/detail review remains available.
- Strategy actions should route into backtest, simulation launch, or detail review workflows rather than mutating strategy definitions silently.
- Canonical strategy names follow `[资产类型][K线周期][策略类型] 标的范围 · 策略名称 · 资金版本`.

## 空态和错误态

- Empty search/filter states should keep filters visible and state that no matching strategy exists.
- Strategies missing explainability fields should show an explicit fallback instead of hiding sections.
