## 页面单元 23：ContractPaperBroker：合约模拟账户

合约模拟使用 ContractPaperBroker，支持 USDT 永续的多空方向、杠杆、名义本金、保证金、资金费率和强平价格模型。策略调用 `open_contract(symbol, "long"|"short", notional_usdt, leverage=...)` 开仓，调用 `close_contract` 按比例或张数平仓。

合约策略的仓位单位和现货不同：入参通常是 USDT 名义本金，页面要关注保证金占用、杠杆、强平距离和多空比。合约策略严禁调用不存在的 open_long/open_short 简写，也不应用现货 buy/sell 代替合约开平仓。
