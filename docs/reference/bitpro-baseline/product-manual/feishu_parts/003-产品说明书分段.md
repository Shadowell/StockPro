## 页面单元 03：安全角色、资金边界与默认模式

BitPro 的默认策略运行语义是 paper/simulation。模拟盘可以使用真实市场数据、真实交易所元数据和真实模型预测，但账户余额、持仓、成交、盈亏、风控状态都来自 paper broker，不应从真实交易所账户派生。

涉及真实 OKX 私钥、账户余额、挂单和实盘订单的页面需要明确进入 `实盘` 工作台，并经过账户绑定、预检、部署确认等步骤。说明书中的实盘章节只解释页面用法和安全边界，不代表建议开启真实资金交易。所有 API Key、Webhook 和 token 都应只在受控环境保存，截图和文档不得暴露明文。
