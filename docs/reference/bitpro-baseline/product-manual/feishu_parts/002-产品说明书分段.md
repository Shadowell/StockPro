## 页面单元 02：全局导航与页面地图

左侧导航是产品的主工作流骨架：`首页` 用于快速看行情与系统状态，`行情` 进入 K 线、AI 预测和订单簿，`数据` 管理 K 线缓存和同步任务，`策略` 管理策略定义，`回测` 做历史验证，`模拟` 启动 paper 实例，`监控` 汇总运行策略和告警，`信号` 管理 OKX Signal Bot 通道，`实盘` 是显式确认后的 OKX Trade API 试运行工作台，`AI策略助手` 承接自主交易、策略研发和策略优化。

建议按“数据 -> 策略 -> 回测 -> 模拟 -> 监控/信号 -> 实盘预检”的顺序使用。直接跳到后置页面虽然可行，但缺少数据覆盖、策略逻辑、风控参数和模拟结果的上下文，容易误判页面指标。
