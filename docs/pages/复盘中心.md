# 复盘中心

最终真实截图：[桌面](../screenshots/rebuild/review-1440x900.png) · [390px](../screenshots/rebuild/review-390x844.png)。

`/review` 按 A股交易日读取和封存市场、股票池、策略、风险、订单、成交与 Paper 表现证据。

- 当前 BitPro 671 行 ReviewDashboard 作为不可达参考源码保留；默认页面复用其“复盘中心”页头、
  KPI、策略分层矩阵、好坏榜和紧凑证据模块，同时保留 StockPro 交易日结论与证据时间线。
- 策略分层矩阵按持久化 metric code 分组，好坏榜只使用 strategy/performance evidence；证据不足时
  显示明确空状态，不从当前 Paper 状态临时推导或制造评分。
- GET 只读取已经持久化的复盘、items 和 metrics；打开页面不会自动 assemble、save 或 seal。
- 管理员可对缺失日期显式组装，编辑 draft 的当日总结/次日计划并封存。
- sealed 复盘及子证据由 PostgreSQL trigger 保证不可修改。
- 时间线对象保留 source object type/ID/route/evidence hash；缺失对象不伪造。
