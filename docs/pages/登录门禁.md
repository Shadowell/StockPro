# 登录门禁页面合同

## 页面目的

登录门禁保护 StockPro 管理员能力，并为受限研究访客提供临时邀请码入口。当前合同不提供
自助注册、短信或邮箱登录，也不在浏览器持久化 Bearer token。

## 路由与当前 API

- 登录没有独立公开路由。`AuthProvider` 首先读取 `GET /api/auth/me`；认证开启且无有效
  session 时渲染 `Login`，不挂载 `MainLayout`。
- 管理员：`POST /api/auth/admin/login`。
- 访客：`POST /api/auth/guest/login`。
- 当前身份：`GET /api/auth/me`。
- 退出：`POST /api/auth/logout`。
- 不存在带版本号入口、redirect、alias Router 或第二套认证 Service。

## 安全与数据边界

- 管理员用户名、密码和 token 签名密钥只从环境读取；密码使用常量时间比较。
- Token 使用 HMAC-SHA256、随机 session ID 和显式有效期。登录同时设置 HttpOnly、
  SameSite=Strict Cookie；生产 HTTPS 环境必须开启 Secure。
- 访客邀请码只以 SHA-256 查询 `guest_access_codes`；服务端不保存或恢复明文邀请码，
  每次解析访客 token 都按 code ID 复核撤销与过期状态。
- 成功和失败写入 `auth_audit_events`，只记录结果与原因码，不记录密码、邀请码或 token。
- 同一来源 15 分钟内最多 10 次失败登录；超过后返回 429。
- 客户端 `normalizeSession` 使用字段 allowlist，明确丢弃登录响应中的 access token；禁止
  localStorage 和 sessionStorage 保存认证凭据。

## 权限

- 管理员权限：`read`、`write`、`admin`。
- 访客权限：`read`、`backtest:run`；后续写 Router 必须在服务端再次检查，不把 DOM
  隐藏当作安全边界。
- 未登录访问业务接口（如 `/api/market/overview`）返回 401；前端据此跳转登录门禁，
  不把 DOM 隐藏当作安全边界。

## 页面状态

- Loading：全屏显示“正在检查登录态…”。
- 未登录、过期或撤销：保持登录页，显示统一错误，不泄露账号是否存在。
- 认证未配置：后端返回 503；不得自动关闭认证或使用默认密码。
- 认证关闭：仅用于明确配置的本地环境，主 shell 以本地管理员身份显示。

## 当前验证与截图合同

- 单元/API：管理员、访客、无效凭据、旧路径 404、HttpOnly Cookie、动态撤销、审计和
  登录限流均有合同测试。
- 真实隔离库：管理员登录、Cookie session、`/api/auth/me`、退出和审计追加已通过。
- Wave 1 不把 mock 登录截图作为产品证据。正式截图必须来自当前 worktree 的真实认证
  配置，且不得包含密码、邀请码、Cookie 或 token。
