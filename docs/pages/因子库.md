# 因子库页面合同

最终真实截图：[桌面](../screenshots/rebuild/factors-1440x900.png) · [390px](../screenshots/rebuild/factors-390x844.png)。

## 路由与职责

- 页面：`/factorlab`；`/factors` 仅保留兼容重定向。
- 当前 API：`/api/v2/factorlab/*`。
- 因子库管理定义、不可变版本、封存输入计算、指标成熟、相关性、值和快照；目录存在、
  python code valid 或 coverage 非空都不等于因子具有经济有效性。

## 页面结构

- 当前 `FactorLab.tsx` 使用 StockPro 的受控研究任务/Trial 工作台，明确区分
  “注册 / 可计算 / 已物化”；数量完全来自 PostgreSQL，不维护“默认 26 个”等第二口径。短线、流动性、
  涨停、跳空和日内收益因子均保持连续值语义。任何
  Provider 研究任务都必须生成可追溯 trial/event 记录，不能连接 Paper/Live 或写入策略运行态。
- 左侧目录支持代码/名称搜索、category 筛选，显示 research status 与最后计算日。
- 已注册参数实例展示 instance id、定义版本、参数 JSON、所需 K 线和默认/已注册状态。
- 每个定义显示输入数据集、row count、最新交易日、有效不可变版本、最新值数和缺失原因；
  sealed factor snapshot 显示真实 manifest hash。
- 详情头显示 factor code、exploratory/candidate/promoted 状态和 Coverage、Rank IC、ICIR、
  Long-short；缺失值保持 `—`。
- `指标诊断` 展示 metric、horizon、value 和 pending_reason；未来收益未成熟时 value 必须
  为 null，不得用 0 或目录 KPI 回填。
- `运行记录` 显示 compute run、trade date、status 与 dataset/universe snapshot。
- `相关性` 显示同一 trade date/universe 的成对相关性。
- `封存快照` 显示 status、factor count 与 manifest hash。
- `值浏览` 分页读取 processed value、rank、quantile 和证券名称。
- 计算表单必须显式指定 active version、trade date、sealed dataset 和 universe snapshot，
  不读取当前行情或自动选择最新输入。

## 运行与安全边界

- `FactorResearchService` 只使用 PostgreSQL 封存 dataset/universe；provider normalizer 已在
  因子模块本地化，读取目录/指标不会导入或调用 TuShare/AKShare。
- 原 BitPro SQLite FactorLab 和旧 `factor_sync_service` 不进入当前运行面。
- 自定义因子代码经过 AST allowlist，禁止文件、网络、数据库、import、eval/exec 和未声明
  数据字段；计算失败不能生成假值或“已验证”状态。
- GET 全部只读；create/version/validate/compute 需要管理员。
- `POST /api/v2/factorlab/research/tasks` 只读取 sealed factor values 并写任务/Trial ledger；
  coverage、OOS fold、20bps/40bps 等硬门槛失败必须以 rejected Trial 持久化，不能生成假候选，
  `orders_created=0`、`paper_mutated=false`。

## 验收

- API 测试锁定 pending rank_ic 为 null 且保留原因，旧版本路径 404。
- 生产当前基线为 20 个注册定义、1 个有效不可变版本、1 个 sealed snapshot、3 条最新值；
  其余 19 个定义明确显示“缺少有效版本”。隔离完整库可按同一合同展示更多定义/版本/值。
- Mock 页面 E2E 验证不出现“已验证”冒领；页面加载 mutation 0。
- 真实桌面/390px、console errors 0、业务写入 0；截图位于忽略目录
  `frontend/output/playwright/wave2-factors-real-*.png`。
