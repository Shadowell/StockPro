# 监控

最终真实截图：[桌面](../screenshots/rebuild/monitor-1440x900.png) · [390px](../screenshots/rebuild/monitor-390x844.png)。

`/monitor` 汇总 PostgreSQL 服务、数据、Paper 策略、风险告警和通知证据。

- Paper `lifecycle_status` 与 `health_state` 独立：stale/missing/failed 健康状态不会改写
  running/paused/stopped 生命周期。
- 服务 evidence time 与页面 response generation time 分离；刷新页面不制造新的健康证据。
- 数据缺失显示 missing/`—`，不显示虚假 0。
- 页面不读取真实券商账户、数字资产策略或交易所连接。
