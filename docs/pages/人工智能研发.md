# 人工智能研发

最终真实截图：[桌面](../screenshots/rebuild/ai-lab-1440x900.png) · [390px](../screenshots/rebuild/ai-lab-390x844.png)。

`/ai-lab` 使用当前 BitPro “AI策略助手”页头和大卡片导航，包含自动交易Agent、受控 AI自主研究、
新策略研发和现有策略优化四个工作区；星球发帖不进入 StockPro。

- 当前 BitPro AILab 与 AutoAgent/ResearchWorkbench/Orbit/support 源码作为不可达参考保留；默认
  页面唯一使用当前 `/api/v2/agent/*`、`/api/v2/research-workbench/*`、`/api/v2/arc/*`
  和 `/api/v2/strategies` 合同；真实交易 live 路由不可达。
- 自动交易Agent执行 Planner→候选代码→AST 沙箱→Quick 回测→评估闭环；AI自主研究只汇总受控任务，
  不能直接控制 Paper；新策略研发展示迭代证据；现有策略优化创建独立任务和新版本。
- 模型只消费已封存的 dataset、Universe、股票池和因子 manifest，以及用户的 A股研究目标。
- 未配置模型、证据不足、模型失败或 AST 验证失败时任务明确 failed，不生成示例、随机或模板输出。
- 候选必须通过当前策略合同验证，只允许 quick replay。保存候选不会运行完整回测，也不会创建
  或控制 Paper；后续仍需回测控制台完成晋级门控。
- 页面不包含数字资产持仓、发帖、自动实盘或自动模拟入口。
