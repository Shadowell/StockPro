# 基本面页面合同

## 路由与事实源

- 路径：`/onchain`，导航名称“基本面”。
- `GET /api/v2/onchain/summary?symbol=` 只读 sealed `daily_basic` 估值和
  `fundamental_factor_facts` 公告时点事实；页面 GET 不调用 Provider、不写库。
- `POST /api/v2/onchain/sync` 仅管理员显式触发，读取 TuShare `fina_indicator`、
  `stk_holdernumber` 和 `dividend`，写入不可变 PIT facts；不创建策略、回测、Paper 或订单。

## 页面结构

- 股票中文名/代码搜索与报告期选择。
- 估值：PE/PB/PS、总市值、流通市值、股息率，显示交易日和 sealed snapshot。
- 盈利与质量：ROE、ROA、毛利率、净利率。
- 成长与资本结构：营收同比、净利润同比、经营现金流/营收、资产负债率。
- 股东与分红：股东户数、每股现金分红。
- 公告证据表：报告期、公告日、可用时间、Provider、revision 和 definition version。

## 安全与状态

- `as_of` 截止日前未公告的数据不可见；无公告日的记录不写入。
- 缺估值或财务事实分别显示 partial/missing_inputs，null 显示 `—`，不转为 0。
- 金额只使用 CNY；页面不得出现 DeFi、链、协议、稳定币、APY 或美元语义。
- 同步响应固定 `orders_created=0`、`paper_mutated=false`。
