# 行情页面合同

最终真实截图：[桌面](../screenshots/rebuild/market-1440x900.png) · [390px](../screenshots/rebuild/market-390x844.png)。

## 路由与定位

- 路径：`/market`。
- URL 状态：`symbol` 保存证券代码，`tab` 保存 `chart`、`orderbook`、`watchlist` 或
  `evidence`；页面刷新和首页指数跳转不得丢失当前对象。
- 页面只覆盖 A股股票、ETF 和指数；不显示合约、永续、资金费率或数字资产交易所控制。

## 当前 API

- 当前 BitPro-first 页面实际读取 `/api/v2/market/*`：`ticker`、`tickers`、`symbols`、
  `klines`、`indicators`、`orderbook`、`trades`。
- `GET /api/v2/market/symbols`：优先读取 PostgreSQL `instrument_definitions` 全量证券；
  当本地/隔离库尚无股票定义时，允许只读拉取 AKShare `stock_zh_a_spot_em` 沪深京 A 股列表
  作为展示兜底；若东财实时列表不可用，可退到 AKShare `stock_info_a_code_name` 代码简称列表。
  该路径不写库、不替代管理员同步结果。
- `GET /api/v2/market/klines`：`1d` 读取 `stock_history`；`1m/5m/15m/30m/60m`
  优先读取 `minute_bars` 缓存，缓存空、不可用或 stale 时允许只读拉取 AKShare
  `stock_zh_a_hist_min_em` 最近分时数据作为显式 fallback；东财接口不可用时可退到 AKShare
  `stock_zh_a_minute` 新浪分时。响应 `data` 保持 K 线数组以兼容图表，
  `meta.data_status`、`meta.provider_source`、`meta.external_fetch` 和 `meta.unavailable_reason`
  区分 ok/stale/empty/provider_error/unsupported，不用静默空数组冒充正常。
- `GET /api/v2/market/orderbook`：读取最新 `orderbook_snapshots`，有缓存时返回 bids/asks、
  trade_date、snapshot_at、source、source_updated_at、collected_at 和 freshness；无缓存时
  返回空 bids/asks 和明确原因。
- `GET /api/v2/market/trades`：读取 `trade_ticks` 近期成交；响应 `data` 保持数组，
  `meta` 标明 ok/stale/empty 与原因。
- `GET /api/v2/market/phase`：交易阶段、交易日和市场开闭市状态。
- `GET /api/v2/market/sector-rps` 与 `/sector-rps/{sector_code}/history`：行业强弱与历史。
- `GET /api/v2/market/movers` 与 `/movers/{symbol}`：已物化异动边缘列表和单标的详情。
- 自选、证券合同、日线、分时、盘口和成交均走 `/api/v2/market/*` 当前域；不存在
  `/stocks/*`、`/api/market/*` 旧 market alias 或 `/api/paper/*` 业务路径。

## 页面结构

- 当前 BitPro `Market.tsx` 原样保存在页面模块作为 named reference；默认导出指向独立
  `AshareMarketWorkspace`，保留同一 Market Terminal/K线/盘口/最近成交布局边界并使用 A 股 API。
- 顶部保留 BitPro `Market Terminal` 节奏，提供全部/股票/ETF/指数筛选和可键盘操作的
  证券搜索弹层。
- 证券概览显示名称、规范化 symbol、asset class、lot size、最新价、涨跌、交易所、
  CNY、tick size 和 stale/fresh 状态。A股股票明确显示 `100股`。
- `K线` 使用 BitPro ECharts 组件，日线注明未复权研究价格、PostgreSQL source 和状态；
  成交量单位为股、成交额单位为 CNY，不显示 USDT。
- `盘口` 只使用未复权可交易价格；当前隔离库没有盘口缓存时显示“隔离库尚无盘口缓存”，
  bids/asks 保持空数组，不用 K线 close 合成盘口。
- `自选` 只持久化 owner、symbol 和 note；价格、涨跌和更新时间每次从行情缓存联查。
- `证据` 显示行情来源、更新时间、复权口径和交易日历。

## 数据与错误边界

- 页面普通 GET 不触发同步或写库；分钟 K 线 GET 在缓存空、不可用或 stale 时可实时拉取
  AKShare 分时接口，并必须在 `meta` 和页面证据条中标明外部来源、状态和失败原因。
  证券列表 GET 在仓库空时可只读拉取 AKShare 全量 A 股列表作为展示兜底；日线、盘口和逐笔
  GET 仍只读缓存，不用分钟线伪造盘口或逐笔成交。
- 股票/ETF/指数分类、SH/SZ/BJ、tick size、lot size 和规范化 symbol 集中在领域/Repository，
  页面不重复推断。
- 日线、分时、盘口分别保留自己的 source/status；来源冲突或缺失不得合并成一个假价格。
- Loading、未选证券、404、无日线、无盘口和空自选都保持稳定容器尺寸。
