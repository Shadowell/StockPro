# 信号中心

最终真实截图：[桌面](../screenshots/rebuild/signals-1440x900.png) · [390px](../screenshots/rebuild/signals-390x844.png)。

`/signals` 是运行信号的审计入口，不是交易执行入口。

- 当前 BitPro 2050 行信号中心作为不可达参考源码保留；默认页面复用其页头、双配置区、
  信号策略列表、策略信号主表和详情抽屉节奏，但唯一读取当前 `/api/v2/signals`、
  `/api/v2/signal-channels`、`/api/v2/signal-strategies` 与 `/api/v2/monitor/events`。
- “通道配置”只读汇总通知投递状态，不保存 webhook、令牌或保证金；“信号策略列表”按
  不可变策略版本和 Paper lineage 聚合信号/待确认数量；没有 OKX Bot 或真实发送测试。
- 读取当前 `/api/v2/signals*`，每条信号保留 signal ID、策略版本、证券、时间、payload evidence
  和 `paper_instance_id`。
- 支持状态/证券/Paper ID 筛选、详情和投递证据浏览。
- 管理员可以把 `new` 信号确认为 `confirmed`；确认不删除或改写 payload、source ID 与
  Paper lineage。访客只读。
- 页面没有买入、卖出或下单动作。
