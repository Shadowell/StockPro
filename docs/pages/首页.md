# 首页页面合同

## 路由与定位

- 路径：`/`。
- 侧边栏：`首页` / `LayoutDashboard`。
- 首页是传统金融操作台总览入口，后续汇总指数、市场宽度、涨跌停生态、板块、自选、
  策略、回测和 Paper 状态；不承载数字资产账户、实盘或链上能力。

## Wave 1 当前状态

当前只交付 BitPro MainLayout 和诚实的 `UnavailableWorkspace`：

- 显示 Owner route、未注册业务服务和 PostgreSQL 数据边界。
- 固定提示“正在接入 A股 PostgreSQL 数据”。
- 不发起市场业务请求，不展示 mock/seed/随机行情，不触发 Provider、scheduler、策略、
  Paper recovery 或数据库写入。
- MainLayout、导航、错误边界和 Outlet 尺寸稳定；切换到策略等页面时侧栏不卸载。

## 后续真实数据合同

Wave 2 才能接入以下模块，并且全部来自唯一 `/api/*` → Application Service → PostgreSQL：

- 上证指数、深证成指、创业板指、科创综指及来源时间。
- 涨跌平、强弱分布、成交额、换手和量比。
- 涨停/跌停/连板生态、板块与行业热度。
- 自选、策略、回测、Paper、告警和数据健康摘要。

任何字段缺失时必须显示 Loading、Empty、Partial、Stale 或 Error，不得把缺失值变成业务
零，也不得为了截图创建 Paper、股票池或行情记录。

## 布局合同

- 继承 BitPro 的近黑画布、低对比卡片、细边框、蓝色交互强调、紧凑数字和稳定 KPI 网格。
- 使用 `text-up` / `text-down`，遵循运行时红涨绿跌设置，不在组件逻辑中硬编码颜色语义。
- Desktop 使用全宽信息带与数据网格；窄屏改为纵向卡片，不挤压数值列，不产生页面级
  横向溢出。
- 不使用营销 Hero、装饰性渐变、虚构在线状态或长篇功能说明。

## 当前验证与截图合同

- Mock Shell E2E 覆盖批准导航、禁止入口、跨路由常驻和 390×844 窄屏无横向溢出。
- Wave 1 桌面/窄屏截图只证明 shell 和诚实未适配状态，不代表首页业务完成。
- Wave 2 首页完成后，必须从真实 A股数据环境重新采集桌面与窄屏截图，并同时记录 API
  来源、数据时间、空态/错误态和 Paper 连续性结果。
