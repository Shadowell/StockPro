# 首页页面合同

最终真实截图：[桌面](../screenshots/rebuild/home-1440x900.png) · [390px](../screenshots/rebuild/home-390x844.png)。

## 路由与定位

- 路径：`/`。
- 侧边栏：`首页` / `LayoutDashboard`。
- 首页是传统金融操作台总览入口，汇总指数、市场宽度、涨跌停生态、板块资金证据与
  策略→回测→模拟主线状态；不承载数字资产账户、实盘或链上能力。

## Issue #61 当前实现

首页基础层只通过 `GET /api/v2/market/overview` 读取一份 PostgreSQL 事实合同；该请求不会
调用 Provider、同步数据、重算快照或改变 Paper。接口从现有 `all_stocks_realtime` /
`realtime_quotes` 与封存 `daily_bars`、`benchmark_bars`、`suspensions` 读取数据：

- `指数行情` 至少展示上证指数、深证成指、创业板指、沪深 300 的真实点位、涨跌、代码、交易日和来源；
  `market_indices_realtime` 为空时只读回退到封存 `benchmark_bars`，不拿股票代替指数。
- `市场宽度 · 涨跌分布` 使用同一有效股票池对账上涨/平盘/下跌、上涨占比、强弱阈值、平均涨跌、
  中位涨跌和八档分布；停牌、无价和坏数据计入排除原因，不进入分母。
- `趋势强度` 只有每个标的至少 60 个确认交易日时才计算 MA5/20/60、新高/新低和新高/新低比；
  历史不足时保持 `blocked` 与 `null`，不填默认 0。
- `成交与换手` 明确展示 CNY 成交额、个股平均成交额、换手率百分比、量比倍数及各自分母；
  `排行榜` 共用同一股票池，提供涨幅、跌幅、成交额和活跃换手四榜，点击进入 StockPro 行情页。
- 顶部证据条显示交易日、盘中实时/盘后快照、Provider、快照 ID、最近成功时间、状态和缺失输入。

## 数据状态合同

- Loading 使用稳定 skeleton；overview 请求失败显示核心错误面板。
- `ready`、`partial`、`blocked`、`stale`、`empty`、`error` 直接展示在状态 badge，不改写来源判断。
- 指数、宽度、趋势、活跃度和排行分别保留自己的状态；一个模块缺失不把其他模块伪装为空或 0。
- 数值 `null` 显示 `—`，不得变成 0；Decimal 通过 API 字符串传输，展示层显式验证再格式化。
- GET 不写库、不调用 TuShare/AKShare、不触发同步、快照、Provider、scheduler、策略或 Paper recovery。

## 布局合同

- 继承 BitPro 的近黑画布、低对比卡片、细边框、蓝色交互强调、紧凑数字和稳定 KPI 网格。
- 使用 `text-up` / `text-down`，遵循运行时红涨绿跌设置，不在组件逻辑中硬编码颜色语义。
- Desktop 使用全宽信息带与数据网格；窄屏改为纵向卡片，不挤压数值列，不产生页面级
  横向溢出。
- 不使用营销 Hero、装饰性渐变、虚构在线状态或长篇功能说明。
