# 回测页面合同

最终真实截图：[桌面](../screenshots/rebuild/backtest-1440x900.png) · [390px](../screenshots/rebuild/backtest-390x844.png)。

## 路由与当前 API

- 页面：`/backtest`，可通过 `strategy_version_id` 深链预选策略。
- API 全部位于 `/api/v2/backtest/*`。当前已注册入口以运行时 OpenAPI 为准，核心包括
  configuration、results/result、run_job、job、jobs、strategies 与运行控制。
- 不存在旧 `/api/backtest/*` Router。

## 页面结构

- 页面直接继承当前 BitPro 的回测工作台：回测实例主表、左侧状态/资产/周期筛选、搜索、
  多列排序、2–4 条结果对比、批量回测、异步进度、状态/日志动作和整页详情；不重新设计信息架构。
- 实例表显示真实 run 的策略/证券、周期、区间、收益、回撤、Sharpe、成交、状态、创建时间
  和操作；详情按需读取权益、指标、订单、成交、持仓、日志和 A 股 K 线，不在首屏读取全部 ledger。
- 创建向导固定三步：选择策略、配置参数、确认运行。运行模式明确区分快速预检和完整协议；
  必须绑定 strategy、dataset、universe、cost，pool/factor/protocol 按模式绑定或显示不绑定。
- 向导明确 A股 T+1、100股、只做多；使用人民币初始资金、股票/ETF、沪深300基准、A股佣金/
  印花税/过户费/滑点语义，不显示币种、交易对、USDT、现货或合约。
- PostgreSQL 历史 run 是不可变证据，页面不显示删除入口；只有未落库的本地实例可以移除。

## 撮合与晋级边界

- A股引擎处理交易日、T+1、100股整手、涨跌停、停牌、未复权成交价、成本、容量、公司
  行为、基准和无未来数据。
- quick 强制 `promotion_status=not_evaluated`；matrix 每个 cell 同样不可晋级；Walk-forward
  每个 fold `promotion_eligible=false`。
- 只有 full run 绑定 sealed protocol、cost、strategy、dataset、universe、pool/factor（如需），
  并通过训练/验证/OOS/容量/基准/数据质量全部门控，才可进入 Paper 申请。
- GET 只读；页面打开不恢复 job、不创建 run、不运行 worker。

## 验收

- 后端门控测试覆盖 quick/matrix/Walk-forward/full；无 active job 时 recovery 返回 0，状态
  分布不变。
- 真实隔离库读取 79 runs、35 jobs，八张 backtest/Paper 表前后不变，Provider imports 0，
  public version names 0。
- Mock E2E 覆盖 BitPro 标题、批量回测、实例搜索、历史表、向导三步、T+1 和 100股。
- 真实桌面显示 79 runs、76 success、50 full、35 jobs；390px 向导无页面级横向溢出，
  console errors 0、业务写入 0。截图位于忽略目录
  `frontend/output/playwright/wave3-backtest-real-*.png`。
