# 回测页面合同

## 路由与当前 API

- 页面：`/backtest`，可通过 `strategy_version_id` 深链预选策略。
- API 全部位于 `/api/backtest/*`：configuration、runs、详情、metrics、series、orders、
  trades、positions、logs、compare、jobs、matrix 与 Walk-forward。
- 不存在旧 Router 或带版本号路径。

## 页面结构

- 顶部 KPI 显示历史 run、成功、完整协议和 job 数；工具栏包含刷新、参数矩阵、
  Walk-forward 和创建实例。
- 历史表一次显示真实 run 的名称/策略、区间、mode、收益、Sharpe、回撤、晋级与状态；
  点击后按需加载详情，不在首屏读取全部 ledger。
- 任务队列显示 status、phase、progress、message 与停止动作；cancel/retry 只作用明确 job ID。
- 创建向导固定三步：选择策略、配置参数、确认运行。必须绑定 strategy、dataset、universe、
  cost；pool/factor/protocol 按模式明确绑定或标记不绑定。
- 向导明确 A股 T+1、100股、只做多和诊断不可晋级。
- 详情抽屉按需加载 metrics、series、orders、trades、positions 和 logs。

## 撮合与晋级边界

- A股引擎处理交易日、T+1、100股整手、涨跌停、停牌、未复权成交价、成本、容量、公司
  行为、基准和无未来数据。
- quick 强制 `promotion_status=not_evaluated`；matrix 每个 cell 同样不可晋级；Walk-forward
  每个 fold `promotion_eligible=false`。
- 只有 full run 绑定 sealed protocol、cost、strategy、dataset、universe、pool/factor（如需），
  并通过训练/验证/OOS/容量/基准/数据质量全部门控，才可进入 Paper 申请。
- GET 只读；页面打开不恢复 job、不创建 run、不运行 worker。

## 验收

- 后端门控测试覆盖 quick/matrix/Walk-forward/full；无 active job 时 recovery 返回 0，状态
  分布不变。
- 真实隔离库读取 79 runs、35 jobs，八张 backtest/Paper 表前后不变，Provider imports 0，
  public version names 0。
- Mock E2E 覆盖历史表、向导三步、T+1 和 100股。
- 真实桌面显示 79 runs、76 success、50 full、35 jobs；390px 向导无页面级横向溢出，
  console errors 0、业务写入 0。截图位于忽略目录
  `frontend/output/playwright/wave3-backtest-real-*.png`。
