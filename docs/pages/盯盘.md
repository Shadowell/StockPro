# 盯盘

最终真实截图：[桌面](../screenshots/rebuild/watch-1440x900.png) · [390px](../screenshots/rebuild/watch-390x844.png)。

`/watch` 负责观察同一 PostgreSQL Paper 证据链，包含策略信号、订单与成交、证券联动、
规则和告警五个工作区。

- BitPro 对应的 765 行 `WatchMarket.tsx` 和 `LiveAccountSummaryPanels` 已原样导入为未注册参考；
  默认 `/watch` 继续使用 A 股 `Watch.tsx`，不读取 live account、衍生品或交易所私有数据。
- 页面读取 `/api/watch/context`、alerts 和 rules；不读取券商私有账户。
- 规则 preview 是零写入操作。管理员显式 evaluate 前必须确认“只生成告警，不下单、不改
  Paper”；响应中的 `orders_created` 固定为 0。
- evaluate 只允许幂等新增 alert 和站内 delivery；规则更新创建不可变新版本。
- 页面不提供交易执行按钮；访客不能创建/评估规则或确认告警。
