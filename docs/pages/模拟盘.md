# 模拟盘

最终真实截图：[桌面](../screenshots/rebuild/paper-1440x900.png) · [390px](../screenshots/rebuild/paper-390x844.png)。

`/live` 是 StockPro “策略 → 回测 → 模拟”主线的第三站，`/paper` 仅保留兼容重定向；页面直接读取 PostgreSQL Paper
账本，不复制或重建历史实例。

## 页面合同

- 默认使用完整审计视图展示全部历史实例；业务范围可通过 API 的 `scope=business` 过滤
  acceptance/seed 数据。
- 实例卡展示生命周期、权益、收益、盈亏、成交、持仓和心跳；缺失数值显示 `—`。
- 详情包含账户曲线、当前持仓、成交与事件、风控状态、诊断日志和固定输入证据。
- 持仓数量、价格、市值与浮盈读取统一 Paper snapshot；A 股数量按整数股显示，价格旁显示
  Paper 持仓快照来源和更新时间。成交行展示成交/订单 ID、成交时间和佣金证据。
- 只使用当前 `/api/v2/live/*`；不存在旧版 `/api/paper/*` 或实盘入口。

## 写操作边界

- 访客只读。管理员可以创建草稿并对明确实例执行启动、暂停、恢复或停止。
- 创建必须绑定通过完整门禁的晋级回测及其策略、数据、Universe、因子、股票池和研究协议。
- 页面加载不会自动恢复、推进、配置、清除、归档或重置实例。
- 推进交易日是独立的显式管理员动作，不由详情页轮询触发。

## 数据连续性

本地隔离验收基线为 15 个实例、61 笔订单、47 笔成交、23 个持仓、428 个净值点和
681 个运行事件。页面与 API 验收前后必须运行 `rebuild/verify_paper_continuity.py`，任何
计数下降、实例缺失或关键 lineage/首尾权益变化都视为失败。
